Getting started

This page is a stand-in for a real documentation site. The dev server serves it with the mock Addons API from public/_/readthedocs-addons.json, which describes a pull request build, so every addon that has a bar UI is available.

Flyout v2 demo

Flyout v2 Original flyout

  • The bar at the top shows the active addon. Hover or click the ☰ to switch between Build details, Search, Changed files and Settings.
  • Press / to jump to search and type to see results inline. Up/Down move through the hits, Enter opens one, Esc returns to Build details. Followed hits come back as recent searches while the input is empty. Search filters sit above the hits.
  • Notifications open under the bell at the end of the bar for a few seconds, then fold away; click the bell to read them again. Settings has a theme switch (dark, light, system) and the bar position.
  • Leave the bar alone for a few seconds and it slides away. Hover the handle at the top to bring it back. Turn this off under Settings.
  • Changed files is the existing file tree diff UI. Press d or tick Show diff to toggle the visual diff on the diff page.
  • Your last addon and the position/auto-hide settings are remembered in localStorage.
  • The opt-in itself is remembered too, so following links keeps v2. The × under Settings (or ?readthedocs-flyout-v2=false) switches back.
